# Balde

A budget manager CLI for the AI Agents era.

## Overview

Balde helps you manage budgets directly from your terminal. Built with simplicity and automation in mind, it's designed to fit into modern AI-agent-driven workflows.

## Installation

```sh
cargo install balde
```

## Usage

```sh
balde init
balde add --amount 50.00 --category "infra"
balde summary
```
